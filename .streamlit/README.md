# Streamlit Theme Configuration

This directory contains the custom theme configuration for the Tea by the Sea dashboard.

## Brand Colors

Based on Tea by the Sea Boston's official branding:

- **Primary Blue**: `#0047AB` (Brand royal blue from cups/logo)
- **Ocean Blue**: `#4A90E2` (Lighter accent blue)
- **Light Blue**: `#E3F2FD` (Soft background tints)
- **Text**: `#1E3A5F` (Deep blue-gray for readability)

## Design Elements

- Circular logo design (matching Tea by the Sea branding)
- Ocean gradient themes
- Wave dividers for visual separation
- Clean, professional layout with emoji accents

## Customization

Edit `config.toml` to adjust:
- Primary/secondary colors
- Background colors
- Font styles

Restart Streamlit after making changes:
```bash
python -m streamlit run src/dashboard/app.py
```
